# 實質受益人持股試算

輸入申戶公司的股東與股份；股東為法人時勾選「法人」並續填該法人的股東，工具會逐層穿透，加總每位自然人的直接＋間接持股比例，超過 25% 者以紅色標示。

線上版：<https://jungshianwu.github.io/beneficial-owner-calculator/>

整個工具只有一個 `index.html`，不需要安裝、不需要網路，資料也不會傳到任何地方。

## 使用方式

1. 下載 `index.html`（點檔案後按右上角的 Download，或 Code → Download ZIP 後解壓縮）。
2. 用瀏覽器（Chrome、Edge、Safari）直接雙擊開啟。
3. 填入申戶公司名稱、各股東名稱與股份。股東為法人時勾選「法人」，下方會多出該法人的股東表，繼續填寫；法人的股東仍是法人時可再勾選，層數不限。
4. 右側即時顯示實質受益人名單與計算明細，按「複製結論」可複製文字版。

## 計算規則

1. 總持股比例 ＝ 直接持股 ＋ 各層法人股東持股比例相乘之總和；同一人透過不同路徑持有的股權全部加總。
2. 遇到法人股東一路向上穿透，直到最頂層的自然人。
3. 門檻為嚴格大於 25%（剛好 25% 不算）。

各公司的持股比例 ＝ 該股東股份 ÷ 該公司所填股份合計。

### 範例

A 公司股東：某甲 50,000 股、某乙 20,000 股、B 公司 30,000 股（合計 100,000 股）。
B 公司股東：某乙 80,000 股、某丁 30,000 股（合計 110,000 股）。

- 某甲：直接 50.00% = 50.00%
- 某乙：直接 20.00% + 間接 (30.00% × 72.73%) = 41.82%
- 某丁：間接 (30.00% × 27.27%) = 8.18%

實質受益人：某甲、某乙。

### 其他處理方式

- 同名視為同一人。
- 同一法人出現在多處時，只需填一次股東結構，其餘沿用。
- 交叉持股（法人的股東又是上層公司）或法人未填股東時，該段股權不計入，並提示尚未穿透的比例。
- 比例以分數精確計算，顯示時四捨五入至小數第二位。

## 注意

試算結果僅供參考，實質受益人之認定仍以法規及內部審查為準。
